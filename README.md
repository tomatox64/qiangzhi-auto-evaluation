# 强智教务系统自动评教（通用版）

面向强智教务系统（`/jsxsd/xspj/*`）的学生评教辅助脚本。在原作者 **小哲** v1.1 的基础上新增「全自动模式」：自动遍历所有未评课程，按原有评分策略填充，等待可配置秒数后提交/保存，并自动进入下一门。

> 评分规则、评语生成、快捷键、悬浮球、进度看板等原有能力全部保留，评分逻辑逐行未改。
>
> 本项目是**社区修改版（fork）**：基于原作者 小哲 发布的 v1.1 源码二次开发，新增全自动模式，并非原作者发布版本。

## 安装

1. 安装脚本管理器：[ScriptCat](https://scriptcat.org/) 或 Tampermonkey（Edge / Chrome 均可）。
2. 安装脚本：
   - 打开 `qiangzhi-pingjiao.user.js`，脚本管理器会弹出安装页，点「安装」；或
   - 新建脚本，把代码整段粘贴进去，`Ctrl+S` 保存。
3. 确认脚本的 `@match` 覆盖你学校的教务地址（默认 `*://*/jsxsd/*`）。

## 使用

### 单门模式

进入某门课的评价页 → 点右下角 **⚡ 一键评教**（或 `Alt+Q`）→ 检查高亮项 → 自己点提交（或 `Alt+S`）。

### 全自动模式

1. 打开 **教学评价 → 学生评价** 的课程列表页（带「是否提交」列的那个页面）。
2. 右下角「评教进度」面板里打开 **🤖 自动模式**，确认弹窗会告诉你将处理多少门。
3. 脚本自动执行：进入课程 → 填充 → 等待 → 提交 → 回列表 → 下一门。
4. 随时可停：右上角 HUD 的「停止自动模式」，或脚本菜单里的「停止自动评教」。

> 全自动模式会把「所有未提交课程」按你当前的评分策略真实提交，提交后一般不可修改。第一次使用建议先只跑一门（把「单次最多处理」设为 1）。

## 自动模式的关键逻辑

```
列表页扫描（表头“是否提交”）
   └─ 取第一门「未提交 且 本次未尝试过」的课程
        └─ 解析 javascript:openWindow('...') 里的真实 URL
             └─ 同标签打开（绕开弹窗拦截，便于提交后返回）
                  └─ 等页面加载完成 → fillForm()（原评分逻辑）
                       └─ 倒计时 N 秒（默认 15，可在设置里改）
                            └─ 定位提交按钮并点击
                                 ├─ 明确成功提示 → 回列表 → 下一门
                                 ├─ 8 秒无明确提示 → 回列表按“是否提交”核对
                                 │     ├─ 已提交 → 下一门
                                 │     └─ 仍未评 → 暂停并提示
                                 └─ 明确失败提示 → 暂停 + 弹出系统原文
```

几个容易踩坑、已专门处理的点：

1. **跨页面状态**：每次跳转都是一次完整页面加载，内存变量会清空。运行进度、已尝试课程、列表地址、当前课程名都存在 `GM_setValue` 里，刷新/跳转/关掉再开都能续跑。
2. **按钮文字带空格**：强智的按钮常写成 `value="提  交"`、`"保  存"`，直接按「提交」匹配会失败。脚本会先去掉所有空白再匹配，同时优先用 `#tj` / `input[name="tj"]` / `#btn_xspj_bc` / `input[name="bc"]`。
3. **弹窗会冻结页面**：提交前常有 `confirm('提交后不能修改')`，提交后返回页常用 `alert('保存成功')`。原生弹窗会阻塞整个渲染线程，脚本在**脚本第一行**就改写页面 `alert/confirm`，把文案写进 `data-qzt-dialog` 由脚本读取；`@early-start` 保证抢在页面内联脚本之前。
4. **评价入口是弹窗**：列表里的「评价」多为 `javascript:openWindow(url,1000,700)`。自动模式不点弹窗，而是把 URL 抠出来同标签打开——既不会被浏览器拦截，提交后也能直接回列表。
5. **提交结果可能落在 iframe 里**：本实测站点把表单 POST 到隐藏 iframe，顶层页面不会有任何提示。脚本会跨 frame 读取同源 iframe 的弹窗/正文；仍拿不到就回列表用「是否提交」列做最终判定，而不是靠弹窗猜。
6. **避免死循环 / 重复提交**：每门课进入前把链接记入 `visited`；刚提交过的页面 45 秒内不会再填一次；「未提交」的课全都尝试过就停下来提示，而不是无限重试。
7. **后台标签页节流**：倒计时用绝对时间戳校正，切回前台会立即补算；但长时间挂后台仍可能被浏览器降频，建议保持标签页在前台。

## 配置项

右键悬浮球 → 「评教助手设置」，或脚本菜单 → 「脚本设置」。

| 配置 | 存储键 | 默认 | 范围 | 说明 |
| --- | --- | --- | --- | --- |
| 评分模式 `scoreMode` | `qzt_settings_v3` | `smart` | full / smart / mixed | 沿用原逻辑，未改动 |
| 填充后自动提交（单门） `autoSubmit` | 同上 | `false` | 开关 | 单门模式下填充完自动点提交 |
| 自定义评语库 `customComments` | 同上 | 空 | 多行文本 | 每行一条，留空用内置词库 |
| **自动模式** `autoMode` | 同上 | `false` | 开关 | 总开关；关闭即停止 |
| **提交前等待** `waitSeconds` | 同上 | `15` | 0–120 秒 | 网站限制，默认 15 秒 |
| **提交按钮** `submitMode` | 同上 | `auto` | auto / submit / save | auto = 提交优先，找不到退回保存 |
| **进入下一门间隔** `navDelayMs` | 同上 | `1500` | 300–10000 ms | 太快容易触发站点频控 |
| **单次最多处理** `maxCourses` | 同上 | `40` | 1–200 门 | 安全上限，超过自动暂停 |
| **出错自动暂停** `stopOnError` | 同上 | `true` | 开关 | 关闭则记录错误后继续下一门 |
| **自动确认系统弹窗** `autoConfirm` | 同上 | `true` | 开关 | 关闭后 alert 会正常弹出（会卡住自动流程） |
| **跳过“评价说明”倒计时** `skipIntro` | 同上 | `true` | 开关 | 仅对存在说明页的学校生效 |

运行状态单独存放：`qzt_auto_state_v1`（已尝试课程、成功/失败数、列表地址、当前阶段）。

## 关于「15 秒限制」的调研结论

强智体系里被称作「15 秒」的限制实际有两种，性质完全不同：

**① 评价说明页的 15 秒阅读倒计时（前端）**

多所高校的操作指引里都写明：「点击进入评价，首先需要阅读评价说明，通过 15 秒倒计时后进入评价页面」。这类倒计时由页面 JS 控制按钮的 `disabled`/`class`，属于纯前端门槛。

- 可否绕过：**可以**，等按钮可用即可，或者直接跳过说明页。
- 脚本做法：`skipIntro` 打开时，自动等到「进入评价」可用并点击；如果你的学校根本没有说明页，这项不影响。

**② 提交端的最短停留 / 提交频率校验（后端）**

部分学校会在服务端比对「进入评价页的时间」与「提交时间」，不足阈值就返回「评价时间不能少于 X 秒」。时间戳存在服务端 session 或数据库里。

- 可否绕过：**不能可靠绕过**。改前端 `Date`、改隐藏字段都只影响客户端；除非伪造请求直接打接口，而这会留下异常调用记录，也有被风控/审计的风险。
- 脚本做法：`waitSeconds` 默认 15 秒；真的被拒时不会硬刷，而是暂停并弹出系统原文，提示你调大等待时间。

**建议**：先按默认 15 秒跑一门。如果一次通过，说明你学校没有后端停留校验，可以把 `waitSeconds` 调到 1–2 秒大幅提速；如果被拒，就保持 ≥15 秒。

**本次实测（湖南工商大学 `jwgl.hutb.edu.cn`）**：

- 评价页没有「评价说明」倒计时，点「评价」直接进入表单，`skipIntro` 在此站点不参与流程。
- 9 门课程全部以 15 秒等待提交，**没有出现“时间不足/提交过快”类提示**，也没有观察到服务端最短停留校验。
- 没有用真实评教去试 1 秒提交——提交不可撤销，不值得拿真实数据验证“能不能更快”。想提速的话，建议先用一门非关键课程把 `waitSeconds` 降到 5 秒试水，被拒就调回。

## 兼容性

- 已实测：湖南工商大学 `jwgl.hutb.edu.cn`（强智，列表 `xspj_list.do` / 评价 `xspj_edit.do`，弹窗式入口 + 隐藏 iframe 提交）。
- 通用回退：表头含「是否提交 / 提交状态」即可识别列表；按钮按 `#tj`、`input[name=tj]`、`#btn_xspj_bc`、`input[name=bc]`、文字匹配依次兜底。
- 实验课（文本框打分）页面暂不参与自动模式，会暂停并提示，避免误填。

## 已知限制

- 只处理当前列表页的课程；多页时需翻页后再开一次。
- 提交不可撤销，脚本不会替你判断评分是否“合适”。
- 浏览器对后台标签页有定时器节流，批量运行时请让页面保持前台。
